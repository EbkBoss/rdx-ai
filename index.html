    Activation

    Three steps. No waiting for a human.

    You pay, you paste your PayPal transaction ID, the app asks the licence issuer for the key and checks it on your phone. There is no account, no server and no phone-home after that.

    1 · PAY

    PayPal / exact amount

    Tap the product's Buy button.

    • The amount is already filled in — $12, $99 or $249 for the browser
    • PayPal returns you to the receipt page with your transaction ID written on it
    • You never have to retype it, and you never have to send a screenshot

    2 · PASTE

    One field / inside the app

    Open the app. It shows the price sheet and a box that says PAY, THEN PASTE YOUR RECEIPT ID.

    • Paste the PayPal transaction ID and tap CLAIM
    • The app posts it to the licence issuer, which checks the payment
    • Already have a key? Paste it in the key box — it starts with GVST1.

    3 · UNLOCK

    Offline / checked on the phone

    The key comes back signed. The app verifies the signature against the public key compiled into the build, stores it, and the browser opens.

    • No account, no server call, no telemetry, ever again
    • The app works with the radio off — the licence lives on the phone
    • The screen shows the licence id and the days you have left

    The rules the issuer enforces — and cannot be talked out of

    • One payment = one licence. A transaction ID that already minted a key is refused (HTTP 409). Replaying a receipt never produces a second key.
    • One licence = one phone. A key locked to a device is refused on any other phone: “This licence is locked to a different phone.”
    • No guessing. If the amount paid does not match a plan of that product, the issuer refuses instead of inventing one. An unknown transaction ID comes back PENDING (402) — never a free key.
    • Renewal adds days. Pay again and paste the new transaction ID: the same licence ID is extended, so the days you paid for are never lost and the clock never restarts on time you have not used.
    • One product per key. A Browser key does not open Terminal and a Terminal key does not open the browser — the product is inside the signed payload, so the wrong key is refused instead of half working.
    • A dead end is never a dead end. If a key does not arrive, the activation screen shows a claim card with COPY and EMAIL buttons carrying the product, the plan, your transaction ID and this phone's device code — so one message reaches the builder with everything needed.
