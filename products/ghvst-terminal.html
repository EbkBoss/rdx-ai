Automatic delivery

  1. Pay the exact option on PayPal.
  2. Return to the receipt page and paste the transaction ID once.
  3. The merchant-side issuer checks the real amount and product, then returns the signed licence and any sealed download ticket.
  4. Activate on the bound device. Renewing adds paid days; expiry locks on time with zero grace.

WhatsApp is support fallback, not the automatic delivery mechanism. If an option has no sealed artifact on record, the page says so instead of fabricating a download.

Independent evidence

  • Sealed retail APKs with v2+v3 signatures and SHA-256 manifests
  • Real chat, model selection, HTML artifacts and Android execution are exercised on device
  • Wrong-device activation and subscription expiry are tested

Privacy and security

  • Licence verification is offline after activation
  • NVIDIA and other provider keys are entered by the user and stored in Android Keystore
  • Payment is verified by the issuer; the app does not ship provider credentials

Known limits

  • Vision works only with a genuinely image-capable selected model
  • Some Android actions require accessibility, notification, storage or Shizuku grants
  • Provider failures remain visible; GSG never substitutes a model silently
