Automatic delivery

  1. Pay the exact option on PayPal.
  2. Return to the receipt page and paste the transaction ID once.
  3. The merchant-side issuer checks the real amount and bundle, then returns a separate signed licence for every included product, with each product's sealed download ticket.
  4. Activate each product with its own key on its assigned device. There is no shared master key. Renewing adds paid days; expiry locks on time with zero grace.

WhatsApp is support fallback, not the automatic delivery mechanism. If an option has no sealed artifact on record, the page says so instead of fabricating a download.
