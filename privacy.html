PRIVACY AND SECURITY

What happens to your data.

Offline licence checks, explicit provider choices, device-bound activation, and no hidden public download path. This page distinguishes local state from services you choose to call.

Payment and delivery

  • PayPal processes the payment. The customer supplies only the transaction ID to the issuer.
  • The issuer checks amount, product and transaction state with PayPal before issuing a licence.
  • Provider credentials, the licence private key and signing keys are never embedded in public pages or apps.
  • A non-bundle transaction produces one device-bound key and cannot mint another. A bundle transaction produces only the declared separate product keys, each bound to one device; it never produces a shared master key.
  • GitHub releases remain DRAFT. Downloads are signed tickets against the paid transaction.

Provider requests

  • Cloud AI requests go to the provider and model the user selects; a text-only model is never described as vision-capable.
  • API keys are supplied by the user and stored using the platform keystore where implemented.
  • Images are sent to the selected vision provider only when the user asks for visual analysis.
  • Provider errors and unsupported capabilities are reported honestly.

GHVST - the AI operator for your phone

  • Licence verification is offline after activation
  • NVIDIA and other provider keys are entered by the user and stored in Android Keystore
  • Payment is verified by the issuer; the app does not ship provider credentials

GHVST Workspace - the AI engineering cockpit for Windows

  • Offline signed licence with no account or phone-home requirement
  • Projects and provider configuration stay on the user's machine
  • Cloud model requests go only to the provider the user selects

Ghvst Browser for Android

  • Offline licence verification after purchase
  • Optional AI features use the user's own NVIDIA key, stored on device
  • No account is required for the browser itself

GHVST Capture - screen + camera evidence engine with offline AI

  • The agent link can operate on-device without a cloud account
  • Licence verification is offline
  • Cloud models are optional and use the user's provider configuration

GHVST DevKit - the on-device development workstation

  • Local files and project state stay on the device
  • No cloud account is needed for the local workflow
  • Provider keys are optional and user-controlled

RoxVault - Roblox Account Manager

  • Vault contents remain under the user's control on their machine
  • Account identifiers in public screenshots are masked
  • Export and deletion remain user-initiated actions

Sovereign Messenger (Ghvst Sovereign Gang)

  • Encrypted chat and per-user partner state
  • Provider keys stay in Android Keystore
  • Provider errors are shown rather than silently switching engines

GHOST Apps Licence - every Ghvst app

  • Each product has its own signed licence record and device binding
  • Payment verification happens once per order at the issuer
  • No public APK, shared master key or licence download path

GHVST Capture Suite - Capture + DevKit together

  • Local files and captures stay on the device
  • Offline licence verification
  • Cloud models remain optional and user-configured

GHOST Team Licence

  • Each activated device has its own binding
  • Payment verification uses the transaction ID
  • No shared public licence key

Ghvst Browser - PC

  • Local account and vault state
  • Offline licence verification
  • No shared Android/Windows key is implied

MVRK Studio

  • Project media stays with the user's workflow
  • Offline licence verification
  • Third-party assets remain subject to their own licences
